# Vita Fan Radio

Статический сайт для GitHub Pages. `index.html` перенесён без изменений из последней опубликованной версии Cloudflare Pages.

## Публикация

Для адреса https://stitch9972.github.io/ нужен аккаунт или организация `stitch9972` и репозиторий `stitch9972.github.io`.
На бесплатном тарифе GitHub репозиторий должен быть публичным: исходный HTML и встроенные изображения будут доступны всем.

1. Загрузить `index.html` и `.nojekyll` в корень ветки `main`.
2. В Settings → Pages выбрать Deploy from a branch → main → / (root), сохранить.
3. После завершения публикации проверить публичную страницу.

Текущий сайт https://vitafanradio.pages.dev/ можно оставить без изменений.

## Ограничения

В исходнике указан HTTP-поток Listen2MyRadio. Плеер намеренно не запускает его на HTTPS-странице; перенос на GitHub Pages это не исправляет. Нужен действующий HTTPS-адрес потока от радиохостинга. Источник названий треков не задан.
Доступность GitHub Pages без VPN зависит от сети и региона и не гарантируется.
